Installing the suite

The fastest way to get every app is AxiOM, which installs and updates the rest for you. If you would rather install one app on its own, each has a standalone release.

Requirements

The desktop apps run on Windows and Linux. Combat analysis additionally needs arcdps installed and loading correctly.

  • A Guild Wars 2 installation
  • An API key with the account and guilds scopes
  • Roughly 400 MB of disk for the full suite

Verifying the install

axilog --version
axilog parse ./logs/20260920-wvw.zevtc --summary

If the parser reports zero agents, arcdps wrote the log but the fight never started.

What it does

Watches the arcdps log directory, uploads each new encounter, and posts a summary to a Discord webhook.

  • Per-squad routing
